# Conclusão

A realização deste trabalho permitiu compreender, na prática, como o iptables pode ser utilizado para controlar o tráfego de rede por meio de regras de filtragem e tradução de endereços.

Os dois cenários demonstraram diferentes formas de configurar políticas de segurança, permitindo ou bloqueando conexões de acordo com os serviços, protocolos, endereços e estados dos pacotes.

A atividade também possibilitou exercitar conceitos importantes de redes de computadores e segurança, como filtragem de pacotes, NAT, controle de acesso e gerenciamento de conexões.

Por fim, o projeto contribuiu para o desenvolvimento de conhecimentos práticos sobre configuração de firewalls em ambientes Linux.
